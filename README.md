# WeddingAgency

# Программный комплекс «Информационная система автоматизации сервиса свадебного агентства»

Настоящее программное обеспечение спроектировано в рамках учебной практики по специальности «Информационные системы и программирование». Проект представляет собой Windows-приложение (WPF), предназначенное для комплексной цифровизации работы свадебного агентства. Система успешно решает задачи автоматического ведения клиентской базы, координации базы внешних подрядчиков, сквозного учета финансовых потоков, а также формирования интерактивной аналитики и управленческой отчетности.

---

## Архитектура и стек технологий

* **Тип приложения:** Настольное приложение Windows
* **Архитектурный шаблон:** Page-based Architecture 
* **Технология доступа к данным:** Entity Framework
* **Система управления базами данных:** Microsoft SQL Server

---

## Структурная схема базы данных

База данных содержит взаимосвязанные таблицы для обеспечения полной ссылочной целостности сущностей:
* **`Roles`**, **`Users`** — учетные записи, настройки тем и роли участников системы.
* **`ItemCategories`**, **`Partners`**, **`CatalogItems`** — база независимых подрядчиков, фирм и их персональных прайс-листов.
* **`HolidayProductTypes`**, **`HolidayProducts`** — номенклатурный каталог розничных свадебных товаров.
* **`EventTypes`**, **`EventStatuses`**, **`Events`** — заголовки заказов, бюджеты, даты проведения и их жизненный цикл.
* **`EventItems`** — детальные строки сметных спецификаций каждого мероприятия (состав забронированных залов, тортов, платьев).
* **`TransactionTypes`**, **`PaymentMethods`**, **`Transactions`** — журнал кассы, фиксирующий b2c-поступления от клиентов и b2b-выплаты партнерам.
* **`Reviews`** — модуль обратной связи, оценок и текстовых отзывов от клиентов.

## Перспективы развития и масштабирования (Roadmap)

Разработанная система имеет гибкую модульную архитектуру, что позволяет в будущем расширить её функционал следующими компонентами:
* **Модуль SMS и Email-уведомлений:** Автоматическая отправка клиентам статусов готовности заказа, напоминаний о дате торжества и чеков об оплате.
* **Интеграция с Telegram Bot API:** Разработка бота для клиентов (быстрый просмотр каталога и оформление заявок) и для администратора (оперативные уведомления о новых заказах и кассовых операциях).
* **Модуль интеллектуального прогнозирования:** Использование простейших алгоритмов анализа данных для прогнозирования сезонного спроса на услуги определенных партнеров (например, фотографов или площадок) на основе статистики прошлых лет.

## Обеспечение безопасности и отказоустойчивости

В ходе проектирования информационной системы особое внимание было уделено защите b2b/b2c данных и стабильности работы приложения:
* **Изоляция транзакций:** Все операции с базой данных выполняются в рамках транзакций Entity Framework. При возникновении любой ошибки (например, сбое сети) происходит автоматический откат (`Rollback`), что исключает появление «битых» или незавершенных записей в кассе.
* **Валидация бизнес-логики:** Ввод данных на страницах оформления заказа и карточках редактирования защищен регулярными выражениями и блоками `try-catch`. Система блокирует ввод некорректных цен, отрицательного количества товаров или пустых строк.

## Функциональные модули системы

В соответствии с техническим заданием в рамках практики были спроектированы и реализованы следующие подсистемы:

1. **Модуль аутентификации и разграничения прав:**
   * Разделение интерфейса на 2 роли: Администратор и Клиент (а также неавторизованный Гость с ограниченными правами просмотра витрин).
   * Автоматическая блокировка административных модулей управления и корзины заказа при сессии Гостя.
   * Сквозное шифрование и хранение паролей в поле `PasswordHash` на уровне СУБД.

2. **Модуль администрирования каталога и заморозки номенклатуры:**
   * Полноценные CRUD-операции над услугами партнеров, праздничными товарами и анкетами исполнителей через диалоговое окно `CatalogEditWindow`.
   * Подсистема b2b-заморозки ассортимента: логические чекбоксы `IsActive` (BIT) позволяют админу мягко скрывать неактуальные позиции или блокировать подрядчиков, мгновенно убирая их с витрин клиентов.
   * Интеграция с проводником Windows (`OpenFileDialog`) для привязки фотографий к товарам и партнерам с сохранением полных абсолютных путей в СУБД и их нативным отображением.

3. **Модуль интерактивных витрин и маркетплейса:**
   * Полноценный каталог розничных товаров и предложений партнеров (`ProductCatalogPage`, `PartnerOffersPage`).
   * Реализация стильного дизайна витрин в формате маркетплейса с вертикальными карточками и жесткой пропорцией изображений 3:4 (`Stretch="Uniform"`), предотвращающей обрезание деталей товара.
   * Подсистема поиска по совпадению строк, фильтрации по назначению и динамической сортировки по возрастанию/убыванию цены.

4. **Модуль управления заказами, смет и синхронизации кассы:**
   * Интерактивный диспетчер входящих заявок (`AdminRequestsPage`) и производства (`AdminActiveEventsPage`).
   * Использование технологии `RowDetailsTemplate` на чистых XAML-привязках для плавного разворачивания полных спецификаций сметы (состава залов, тортов, ведущих) прямо под строкой таблицы.
   * Сквозная синхронизация с кассой: при создании заказа автоматически формируются проводки доходов, а при переводе статуса мероприятия в «Отменено» программа автоматически вырезает связанные чеки из таблицы `Transactions` для чистоты аналитики.

5. **Модуль кастомизации, динамической графики и b2b-отчетности:**
   * Смена тем оформления (светлая/темная) с использованием механизма динамических ресурсов `DynamicResource` на уровне оболочки приложения.
   * Динамическая отрисовка графиков чистой прибыли на холсте `Canvas` с автоматическим расчетом высоты столбцов при событии `SizeChanged` и выводом маржи (15% от входящих платежей).
   * Модули экспорта финансовых итогов по месяцам текущего года в форматы Word, Excel (с автоматическим расчетом формул `=SUM` и `=C*0.15`) и PDF с принудительным автоматическим открытием сгенерированного отчета в интернет-браузере по умолчанию.
